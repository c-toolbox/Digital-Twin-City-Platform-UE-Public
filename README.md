# Plugins
The GeoReferencing plugin from UE 4.27 is currently used in the Digital Twin. 

# Third Party
The `Vasttrafik` Module contains swagger-generated unreal files, downloaded from the Västtrafik developer api.
These should mimic the REST api which västtrafik provides, but some manual work has gone into correcting some fields, which were not representative of the data västtrafik responds with.
